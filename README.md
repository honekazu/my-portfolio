# my-portfolio

小さなお店の1ページホームページを作ります｜スマホ対応・最短3日

## 職種

Web制作・ホームページ制作

## 自己紹介

はじめまして。ご覧いただきありがとうございます。
小さな店舗・個人事業主さま向けに、1ページで完結するホームページを制作しています。

「ホームページは欲しいけれど、何ページも作るほどではない」
「メニューや料金、営業時間とアクセスがスマホで見やすく伝われば十分」
というお店さま向けのサービスです。

■ こんなお店・方におすすめです
・開業したばかりで、まず名刺代わりのホームページが欲しい方
・Instagramはあるが、メニューやアクセスをまとめたページがない方
・整体、教室、サロンなど、料金と予約導線をわかりやすくしたい方

■ お約束すること
・スマホ対応は標準で行います
・文章案はこちらで下書きしますので、原稿がなくても大丈夫です
・修正は2回まで無料で対応します
